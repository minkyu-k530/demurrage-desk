# 체선료 데스크 (Demurrage Desk) — 데모 사이트

> **SKALA 교육 프로젝트 프로토타입 · 모든 데이터 가상 · SK에너지/SEAGATE 공식 시스템과 무관**

- 바로 보기: https://minkyu-k530.github.io/demurrage-desk/
- 무엇: 울산 CLX를 가정한 가상 시나리오에서, 터미널이 재는 체선 '시간'을 계약상 체선'료'로 바꾸고 변경마다 이유·대안을 설명하며 사람이 승인하는 에이전트 프로토타입이다. 선박·회사·계약·수치는 모두 가상이고 일부 규칙값은 가정이다.
- 어떻게 도나: 서버 없이 브라우저 안에서 같은 Python 엔진을 [Pyodide](https://pyodide.org)(WebAssembly)로 실행한다. 처음 열 때 Python 런타임(약 10MB)을 CDN에서 내려받아 수십 초 걸릴 수 있고, 그다음부터는 브라우저 캐시를 쓴다.
- 결정(승인·반려)은 이 브라우저의 localStorage에만 저장된다. 다른 사람·다른 기기와 공유되지 않는다. 화면 오른쪽 위 '초기화'로 처음 상태로 돌린다.
- 이 저장소에는 빌드 결과만 있다. 배포할 때마다 통째로 덮어쓴다(소스 저장소는 비공개).
